# Portfolio Website

A responsive personal portfolio built with semantic **HTML5** and modern **CSS3**, created as part of the Full Stack Development course (TCS 300).

## Features
- Fully responsive layout (works on desktop, tablet, mobile)
- Semantic HTML5 tags (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS Box Model and Flexbox-based layout
- Fixed navigation header
- Smooth scroll navigation
- Project showcase with hover effects

## Tech Stack
- HTML5
- CSS3 (Flexbox, media queries)
- Git & GitHub for version control

## Structure
```
portfolio-website/
├── index.html      # Homepage markup
├── style.css       # All styling (Box Model, positioning, responsive)
└── README.md       # This file
```

## How to Run Locally
1. Clone the repo: `git clone https://github.com/YOUR-USERNAME/portfolio-website.git`
2. Open `index.html` in any browser.
